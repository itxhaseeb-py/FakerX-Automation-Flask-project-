FakerX Automation

A Python-based web automation system built with Flask and Selenium.

About This Project

FakerX Automation is a web-based automation system designed to demonstrate practical Python automation, web development, and authentication concepts.

The project provides a public portfolio-style page where visitors can learn about the project and a private dashboard where authenticated users can access the automation system.

What Does the Automation Do?

The automation system uses Selenium to interact with a demo web application automatically.

  1. Open the target website
  2. Search for a product
  3. Find the required product
  4. Open the product page
  5. Read product information
  6. Add the product to the cart
  7. Open the cart
  8. Continue to checkout
  9. Fill customer information
  10. Fill demo payment fields
  11. Reach the final payment stage
Actual payment authorization is intentionally not performed. The automation is designed for demonstration and testing purposes.

How Does the System Work?

The system uses authentication to separate the public project information from the private automation dashboard.

  1. Register an account
  2. Login with your account
  3. Access the private dashboard
  4. Start the Selenium automation
  5. View the automation result
